# OPSODIS Volume

OPSODIS 1 を USB-C で接続したとき、Windows の音量（スライダー・音量キー・ミュート）が効かない問題を直す常駐アプリです。ドライバのインストールは不要です。

## 原因

OPSODIS 1（USB DAC: VID_08BB / PID_2705）は、Windows に対して「本体側で音量を変えられる（ハードウェア音量 -128〜0 dB）」と申告します。
そのため Windows は自分では音を小さくせず、音量の値を本体に送るだけにします。ところが本体はその値を使わないので、音量が変わりません。

## 仕組み

1. OPSODIS 1 のマスター音量とミュートの変化を監視します（`IAudioEndpointVolume` の通知）。
2. その値を Windows 標準の音量カーブで dB に直し、OPSODIS 1 で音を出している全アプリの**セッション音量**（`ISimpleAudioVolume`）にかけます。
3. セッション音量は Windows のオーディオエンジンがソフトウェアで処理するので、本体が音量値を無視しても確実に効きます。

| Windows の音量 | 減衰量 |
|---|---|
| 100% | 0 dB |
| 50% | -10.5 dB |
| 30% | -18.3 dB |
| 10% | -35 dB |
| 0% / ミュート | 無音 |

- 音量ミキサーで個別に設定したアプリの音量は、マスターに対する比率として保たれます。
- 音量を後から出し始めたアプリにも反映されます。USB を抜き差ししたときは自動で繋ぎ直します。
- 終了すると、各アプリのセッション音量をアプリ本来の値に戻します。

## ビルド

```
build.cmd
```

Windows に入っている .NET Framework 4.x の `csc.exe` を使うので、SDK や Visual Studio は不要です。できたファイルは `bin\OpsodisVolume.exe` です。

## 使い方

1. `bin\OpsodisVolume.exe` を起動すると、タスクトレイにスピーカーのアイコンが出ます。
2. アイコンを右クリックすると次のメニューが出ます:
   - **Windowsの音量を反映する**: 機能のオン/オフ
   - **Windows起動時に実行**: `HKCU\...\Run` への登録/解除
   - **音量ミキサーを開く**（アイコンのダブルクリックでも開きます）
   - **終了**
3. `OpsodisVolume.exe --exit` で、常駐中のアプリを正常に終了できます（スクリプト用）。

設定は `HKCU\Software\OpsodisVolume` に保存されます。対象デバイスは、名前に `DeviceKeyword`（既定値 `OPSODIS`）を含む再生デバイスです。

## 注意

- 音量ミキサーの各アプリのバーは、減衰をかけた後の値で表示されます（例: マスター 30% のときは約 12%）。
- 排他モードで再生するアプリ（一部の DAW や ASIO/WASAPI 排他のプレーヤー）は、Windows のミキサーを通らないので音量は変わりません。
- タスクマネージャーで強制終了すると、減衰した音量が各アプリに残ります。もう一度起動するか、音量ミキサーで戻してください。

## 補足

- `bin\Probe.exe`: 再生デバイスの音量の特性と、各セッションの音量を表示します（診断用）。
- `tools\SetVol.cs`, `tools\SetSession.cs`: 動作確認に使った補助ツールです。
- 仮想オーディオデバイス（カーネルドライバ）を作る方法も検討しましたが、署名していないドライバを入れるにはテスト署名モードが必要です。また遅延も増えるため、採用していません。
